資料保存

匯入的題庫、自建的樣板、組合與作答紀錄只存在這個瀏覽器裡，不會上傳到任何地方。
清除瀏覽器資料、使用無痕視窗、換電腦或換瀏覽器就會看不到；Safari 也可能自動清除一段時間沒開啟的網站資料。
之後還想用的話，請用「完整備份」把題庫和作答紀錄一起匯出。
「匯入檔案」可以讀：
・題庫檔（.quizbank.json）、樣板（.template.json）、完整備份檔
・作答紀錄檔（新舊格式都可以，會合併）
・舊版的題庫 questions.json

從 PDF 建立題庫

選擇 PDF 後會自動試過所有樣板，挑解析得最好的一個；也可以自己換樣板。
目前只支援單選題；掃描檔（只有圖片）不支援。
PDF 取出的文字有問題（例如中文斷行或順序亂掉）而且電腦上有 Python 時，可以改用下面的指令，再用「匯入 Python 取出的文字」：
uv run --with pdfplumber python tools/extract_text.py 檔名.pdf > 檔名.txt
樣板都不合？在取出的文字上標記範例，建立新樣板
  1. 用滑鼠選取文字，再按下面的按鈕標記。每一題要標「題號」、每個「選項」（連同 (1)、(A)、① 這類標記一起選）和「答案」。
  2. 至少標 2 題；挑選項數不同、有折行的題目，推出來的規則比較準。
  3. 頁首、頁尾這類不屬於題目的行：點一下那一行，再按「忽略這行」。只有數字的行（頁碼）會自動忽略。
  4. 按「推出樣板」，確認結果後儲存。

題庫資訊

樣板

樣板描述題庫 PDF 的版面（題號、選項、答案的寫法）。
自建的樣板存在這個瀏覽器裡，完整備份會一起帶走；也可以匯出成 .template.json 給別人，用上方的「匯入檔案」匯入。

對不到題庫的作答紀錄

這些紀錄的題目目前不在任何題庫裡（例如題庫被刪除了）。
紀錄會一直保留，之後匯入同一份題庫就會自動接回。
